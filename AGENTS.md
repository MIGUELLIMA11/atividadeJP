# AGENTS.md

## Projeto
Controle de gastos pessoais em React + Vite, com JavaScript/JSX.
Componentes em `src/components`, um por arquivo.

## Comandos
Execute dentro de `controle-gastos`:
- `npm.cmd install`
- `npm.cmd run dev`
- `npm.cmd run lint` (Oxlint)
- `npm.cmd run build`

## Regras
- Responda e comente o código em português.
- Use apenas React e APIs nativas do navegador: não instale bibliotecas novas.
- Use componentes de função e `useState` para o estado.
- Use nomes de variáveis e componentes em português.
- Mostre valores em reais, com duas casas: R$ 12,50.
- Não crie nem edite o RELATORIO.md.
- Não altere arquivos fora da missão atual.
